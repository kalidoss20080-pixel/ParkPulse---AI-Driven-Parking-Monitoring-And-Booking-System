                                                                      ParkPulse - AI Driven Parking Monitoring And Booking System

                                                                                      Project Description 

   An AI and IoT-based application developed to detect available and occupied parking slots in real time, display parking availability through a dashboard, and guide drivers to vacant parking spaces.

                                                                                      Technologies Used 

                                                        Python, OpenCV, YOLO, Flask, HTML, CSS, JavaScript, SQLite and Arduino IDE.

                                                                                         Features 

                                                                        - Detect available and occupied parking slots.
                                                                        - Display real-time parking availability.
                                                                        - Identify the nearest vacant parking slot.
                                                                        - Guide drivers using RGB LED indicators.
                                                                        - Provide driver and operator dashboards.
                                                                        - Support advance parking slot booking.
                                                                        - Automatic number plate recognition (planned feature).
                                                                                   
                                                                                      What I Learned

              Computer vision, AI-based vehicle detection, Python programming, IoT integration, ESP32 communication, database management, dashboard development and project organisation.

                                                                                      Project Status 

                                                     Currently in progress. Hardware implementation, software development and testing are ongoing.
